[i] Sobre o S.T.E.P

// Propósito

O S.T.E.P — Simple Task Execution Platform é um gerenciador de tarefas acadêmicas que não descarta o que foi feito. Cada tarefa concluída vira conhecimento vivo, conectado e compartilhável.

A ideia central é o Canivete Suíço: uma ferramenta, várias lâminas. Cada modo serve um propósito diferente, mas todos trabalham sobre o mesmo estado.

// Manual de uso

[ ] Kanban

Onde você executa as tarefas.

  • Arrastar e soltar move tarefas entre colunas
  • + Nova Tarefa cria uma tarefa
  • Filtros buscam por título, status e prioridade
  • Tarefas concluídas ganham [#] Arquivar e [x] Excluir

[#] Acervo Vivo

Onde você consulta e evolui tarefas concluídas.

  • Lista de tarefas arquivadas ou concluídas
  • ^ Evoluir Tarefa cria uma nova tarefa baseada nesta
  • > Ver detalhes abre o modal com passos, aprendizados e anotações
  • [>] Publicar envia a tarefa para o Legado

[~] Mapa

Onde você descobre conexões entre tarefas.

  • Cada tarefa é um nó; linhas conectam tarefas com tags em comum
  • Clique num nó ou item da lista para abrir detalhes
  • Filtro por tag destaca um grupo

[>] Legado

Onde você compartilha tarefas como tutoriais.

  • Lista de tarefas publicadas
  • [+] Exportar Markdown baixa um arquivo .md
  • [#] Despublicar remove do Legado

= Ações avançadas (modal)

Dentro do modal de detalhes:

  • ^ Evoluir cria nova tarefa com nova etapa
  • > Clonar duplica a tarefa com novo ID
  • [>] Publicar / [#] Despublicar no Legado
  • [x] Excluir apaga permanentemente

Fluxo sugerido

Como usar no dia a dia:

  1. Crie tarefas no Kanban
  2. Arraste para A fazer → Andamento → Revisão → Concluída
  3. Arquive no Acervo
  4. Evolua tarefas recorrentes
  5. Publique no Legado o que vale compartilhar

// Princípios de design

  • Fonte única de verdade: todo o estado vive num único objeto. A tela é uma projeção.
  • Derivação sem mutação: a lista visível é calculada a partir do estado, sem alterar o array original.
  • Ciclo único de atualização: todo evento altera o estado e chama o mesmo ponto de renderização.
  • Separação de responsabilidades: buscar, derivar, renderizar e decidir estado são funções diferentes.
  • Acessibilidade: região de status com aria-live="polite" anuncia cada mudança.
  • Estética de terminal: sem emojis; apenas símbolos, monocromia e alto contraste.

// Atalhos e dicas

  • Use Tab para navegar por todos os controles
  • Pressione Esc ou clique fora do modal para fechá-lo
  • Arraste cartões entre colunas do Kanban para mudar o status
  • Tags conectam tarefas — explore no Mapa
  • Ao arquivar uma tarefa, ela continua acessível no Acervo
